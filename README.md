# pjtra001_Empleabilidad_San_Gabriel
Formulación, planificación y seguimiento del «Programa Integral para la Empleabilidad y la Inclusión Productiva» en el municipio de San Gabriel PJtra001. Contiene la documentación técnica, el diseño de rutas diferenciadas por perfil para jóvenes de 18 a 28 años, y el registro de actividades, tareas y componentes operativos del proyecto
