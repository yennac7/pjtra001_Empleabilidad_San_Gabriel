# Programa Integral para la Empleabilidad y la Inclusión Productiva

## Propósito
Promover la inclusión productiva y la inserción laboral formal de jóvenes en San Gabriel mediante rutas de atención diferenciadas según su perfil.

## Alcance
Programa piloto de 12 meses para 200 jóvenes. Incluye diagnóstico inicial, módulos de competencias laborales y socioemocionales, orientación ocupacional, alianzas empresariales, ruedas de empleo y seguimiento a la inserción.
